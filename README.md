# Insaniquarium Deluxe (C++ port)

A C++ decompilation of Insaniquarium Deluxe 1.1, written from the original binary and work from [Vindirect/WinFish](https://github.com/Vindirect/WinFish).

You must include your own game files to the bin folder.

## Building

Open `WinFish.slnx` in Visual Studio 2026 (v145 toolset, platform x86) and pick:

- **Release** to build the way the original was built. Output goes to `Bin\`.
- **Debug** for work. Output goes to `Bin\Debug\`.
